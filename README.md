# 🍕 Pizza Sales SQL Data Analysis Project

A comprehensive data analysis project using **SQL** to extract key business insights, revenue trends, and customer ordering patterns from a pizza restaurant's database.

---

## 📊 Project Overview
This project focuses on analyzing transactional pizza sales data to answer critical business questions. By writing structured SQL queries, I extracted actionable insights regarding daily/monthly trends, top-selling categories, and revenue contributions.

---

## 🛠️ Tech Stack & Tools Used
* **Database / Query Tool:** MySQL Workbench
* **Language:** SQL (Structured Query Language)
* **Version Control:** Git & GitHub

---

## 📈 Key Business Questions Addressed
The project includes various analytical queries solving problems such as:
1. Retrieve the total number of orders placed.
2. Calculate the total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Identify the most common pizza size ordered.
5. List the top 5 most ordered pizza types along with their quantities.
6. Join the necessary tables to find the total quantity of each pizza category ordered.
7. Determine the distribution of orders by hour of the day.
8. Join relevant tables to find the category-wise distribution of pizzas.
9. Group the orders by date and calculate the average number of pizzas ordered per day.
10. Determine the top 3 most ordered pizza types based on revenue.
11. Calculate the percentage contribution of each pizza type to total revenue.
12. Analyze the cumulative revenue generated over time.
13. Determine the top 3 most ordered pizza types based on revenue for each pizza category.
---

## 📁 Repository Structure
* `Q-1.sql` to `Q-13.sql` - Individual SQL queries answering specific business and revenue questions.
* `SQL_Project.sql` - Database setup script containing table creation queries (`CREATE TABLE` for orders, order_details, etc.).
